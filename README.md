# みちくさ（Web公開版★）

```
michikusa-web/
├── index.html            … アプリ本体
├── manifest.webmanifest  … ホーム画面に追加・共有メニューに出すための設定
├── sw.js                 … ホーム画面アプリとして動かすための部品
├── icons/                … アプリのアイコン
├── api/
│   ├── sync.js     … 「ふたりで使う」の保管場所とのやり取り
│   └── geocode.js  … （任意）サーバー側で座標取得する方式を使う場合のみ必要
└── README.md
```

**座標の取得方法は2通りあります。おすすめは方法①（サーバー不要）です。**

| | ① アプリにAPIキーを入れる（おすすめ） | ② サーバー側に置く |
|---|---|---|
| 必要なファイル | `index.html` だけ | `index.html` + `api` フォルダ |
| Vercelの環境変数 | 不要 | 必要（設定後に再デプロイも必要） |
| キーの置き場所 | この端末の中だけ | サーバー側 |
| 注意点 | キーに「このサイトからのみ」の制限を必ずかける | 手順が多い |

# 方法①：アプリにAPIキーを入れる（サーバー不要）

## ステップ1：Googleの準備

1. https://console.cloud.google.com/ でプロジェクトを作る（例：`michikusa`）
2. 以下の**2つ**を有効にする（URLを直接開くのが早いです）
   - `console.cloud.google.com/apis/library/maps-backend.googleapis.com` → **Maps JavaScript API**
   - `console.cloud.google.com/apis/library/places.googleapis.com` → **Places API (New)**
3. `console.cloud.google.com/apis/credentials` →「認証情報を作成」→「APIキー」→ `AIza…` をコピー
4. **そのキーに必ず制限をかけます**（重要）。作ったキーを開いて：
   - 「**アプリケーションの制限**」→「**ウェブサイト**」を選び、公開したサイトのURLを追加
     - 例：`https://あなたのサイト.vercel.app/*`
   - 「**APIの制限**」→「キーを制限」→ **Maps JavaScript API** と **Places API (New)** だけにチェック
   - これで、他人がキーを見ても他のサイトからは使えなくなります

### 料金について

Places API の Text Search は **毎月5,000回まで無料**です。ピン1,750件なら1,750回なので無料の範囲です。
しかも一度取得した座標は端末に保存され、2回目以降はGoogleに問い合わせません。
（Googleの方針でカード登録自体は必須です。「$300無料トライアル」で始めると、使い切っても自動課金されません）

**念のための上限設定（推奨）**：「APIとサービス」→ 各APIの「割り当てとシステム上限」で1日あたりの上限を
3,000程度にしておくと、それ以上は自動で止まります。

## ステップ2：サイトを公開する

1. https://vercel.com/drop を開き、無料アカウントでログイン
2. この `michikusa-web` フォルダをドラッグ＆ドロップ →「Deploy」
3. 発行された `https://〜.vercel.app` のURLを開く

環境変数の設定も再デプロイも不要です。

## ステップ3：使う

1. 公開URLをスマホのブラウザ（Safari／Chrome。**アプリ内ブラウザではなく**）で開く
2. 「ピンの読み込み・追加」からTakeoutのファイルを読み込む（zipのままOK・複数選択OK）
3. 「座標のないピン」の枠の中の「**APIキーを設定する**」を開き、キーを貼り付けて「保存」
4. 「**座標を一括取得する**」を押す
   - 進捗バーが出ます。途中で「中止」も可能で、そこまでの分は保存されます
   - 見つからなかった店は記録され、無駄な再問い合わせをしません（「もう一度試す」で再挑戦可）
   - 店名検索のため別のお店を拾うことがあります。「名前が一致しなかったピンを確認する」で確認できます
5. 「現在地を取得」→「コース提案」タブでコースを作る

# 方法②：サーバー側に置く

`api/geocode.js` を使う方式です。キーをブラウザに一切出したくない場合はこちら。

1. 上のステップ1と同様にキーを作る（有効化は **Places API (New)** だけでOK。キーの制限は「ウェブサイト」ではなく
   「なし」または「IPアドレス」にします）
2. `michikusa-web` フォルダ**ごと**（`api` フォルダを含めて）Vercelにデプロイ
3. Vercelのプロジェクトで **Settings → Environment Variables** に追加
   - Key: `GOOGLE_MAPS_API_KEY` / Value: APIキー
   - スマホでは `vercel.com/<ユーザー名>/<プロジェクト名>/settings/environment-variables` を直接開くと早いです
4. **Deployments → Redeploy**（環境変数は再デプロイしないと反映されません）
5. アプリ側ではAPIキーを入力しないでください（未入力だと自動的にサーバー側を使います）

確認方法：`（サイトのURL）/api/geocode` を開いて `{"error":"POST のみ対応しています。"}` と出れば正常。
**404 NOT_FOUND** が出る場合は `api` フォルダがデプロイに含まれていません。

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「サーバーに接続できませんでした」「サーバー側の処理が見つかりません」 | 方法①でAPIキーを入力すれば解決します |
| 「Googleの読み込みに失敗しました」 | キーが間違っているか、**Maps JavaScript API** が有効になっていません |
| 「APIキーの設定に問題があります：RefererNotAllowed」 | キーのウェブサイト制限に、今開いているURLが入っていません |
| 「…ApiNotActivated」 | **Places API (New)** が有効になっていません |
| 現在地が取れない | `https://` のURLで開いていますか？ ローカルファイルではGPSは使えません |
| 「サーバーに保管場所がつながっていません」 | 「ふたりで使う」の手順（Storage をつなぐ → Redeploy）がまだです |
| 「このアドレスでは共有機能が使えません」 | Claudeのプレビュー画面では共有できません。Vercelのサイトで開いてください |

# Googleマップの「共有」から1件ずつ追加する

Googleマップでお店を開き「共有」するだけで、みちくさのピンに入ります。
送られるのは「店名・住所・短いリンク」の文字だけで、それをもとに公式の Places API で場所を探します
（リンク先を読みに行くことはしません）。

## Android

1. みちくさを **Chrome** で開き、メニューの「**ホーム画面に追加**」（または「アプリをインストール」）
2. Googleマップでお店を開く →「**共有**」→ 一覧から「**みちくさ**」
3. みちくさが開いて候補が出るので、メモを書いて「ピンに追加」

## iPhone（かんたんな方法）

1. Googleマップでお店を開く →「共有」→「**コピー**」
2. みちくさのピン画面の「**＋**」→「**コピーしたものを貼る**」

## iPhone（共有メニューから直接送る：ショートカットを1つ作る）

iPhoneのブラウザには、共有メニューにサイトを出す仕組みがありません。代わりに「ショートカット」アプリで入口を作ります。
（iOSのバージョンによって表示名が少し違うことがあります）

1. 「ショートカット」アプリ →「＋」で新規作成、名前を「**みちくさに追加**」に
2. 詳細（ⓘ）→「**共有シートに表示**」をオン。受け取る種類は「URL」と「テキスト」
3. アクション「**URLをエンコード**」を追加（対象：ショートカットの入力）
4. アクション「**テキスト**」を追加し、`https://（あなたのサイト）.vercel.app/#add=` と入力して、そのすぐ後ろに「URLエンコードされたテキスト」を差し込む
5. アクション「**URLを開く**」を追加（対象：テキスト）
6. 以後、Googleマップの「共有」→「**みちくさに追加**」で送れます

## ふたりともAPIキーなしで探せるようにする（おすすめ）

APIキーを入れていないスマホで共有すると、場所を探さずに「名前だけ」で入ります（あとで座標を取得できます）。
ふたりとも探せるようにしたいときは、Vercel にキーを置きます（上の「方法②」と同じ）。

1. Vercel の **Settings → Environment Variables** に `GOOGLE_MAPS_API_KEY` を追加
2. **Redeploy**

これで、キーを入れていないスマホでも、サーバー経由で場所を探せます。

# ふたりで使う（ピンを2台で共有する）

## しくみ

```
 妻のスマホ ─┐                         ┌─ 夫のスマホ
             ├─> あなたのVercelサイト ─┤
             │    └ /api/sync          │
             │        └ 保管場所(Redis) │
```

- 「ふたりで使いはじめる」を押すと、**合言葉**（例：`MK-7K3M-9QPX-A2BC`）ができます
- 合言葉ごとに、保管場所の中に「ふたり用の箱」が1つできます
- 各スマホは、アプリを開いたとき・ピンを変えたとき・20秒ごとに、この箱と中身を合わせます
- APIキーと現在地は送りません（ピン・メモ・写真・リスト名だけ）

## 最初に1回だけ：保管場所をつなぐ（5分・無料）

1. Vercel でこのサイトのプロジェクトを開く
2. 上のタブの **Storage** →「**Create Database**」（または「Connect Database」）
3. **Upstash** の「**Redis**」を選ぶ → 無料プラン（Free）→ 地域は **Tokyo (ap-northeast-1)** があればそれ
4. 「Connect to Project」で、このサイトのプロジェクトにつなぐ（環境変数が自動で入ります）
5. **Deployments** → いちばん上の「…」→ **Redeploy**（つないだ設定は、再デプロイしないと反映されません）

確認：`（サイトのURL）/api/sync?ping=1` を開いて `{"ok":true,"storage":true}` と出ればOK。
`"storage":false` のときは、手順4か5がまだです。

## 使い方

1. 片方のスマホ：設定 →「ふたりで使う」→「**ふたりで使いはじめる**」→「**招待を送る**」でLINEに送る
2. もう片方：LINEのリンクを開く →「共有しますか？」で OK
3. あとは、どちらがピンを足しても直しても、もう一方にも入ります

## 気をつけること

- 合言葉を知っている人は中身を見られます。ふたり以外に教えないでください
- 同じピンを2人がほぼ同時に直したときは、**あとから届いた方**が残ります
- 共有中にピンを読み込むと、置き換えではなく**追加**になります（相手のピンを消さないため）
- 無料枠（Upstash Free）は、ふたりで使うには十分な量です

## データの保存先

- ピン・座標・APIキーは、まず**その端末のブラウザの中**に保存されます
- 「ふたりで使う」を始めた場合だけ、ピン・メモ・写真が**あなたのVercelにつないだ保管場所**にも保存されます
- APIキーはどこにも送られません
